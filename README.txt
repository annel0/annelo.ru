annelo.ru — личный сайт Александра

Веб-сервисы, автоматизация, инфраструктура, электроника и 3D-печать.
Статический сайт без сборки, внешних библиотек и платных API.

Структура
  dist/index.html — содержимое страницы
  dist/style.css — оформление, адаптация и темы
  dist/script.js — навигация, тема, вкладки и копирование почты
  dist/assets/ — иллюстрации
  .github/workflows/pages.yml — публикация в GitHub Pages

Локальный просмотр
  python3 -m http.server 8766 --directory dist
  Открыть http://localhost:8766

Публикация
  GitHub Pages использует GitHub Actions. При push в main публикуется
  только папка dist, а не служебные файлы репозитория.
  Домен annelo.ru подключается отдельно после настройки DNS.

Оформление
  Светлая и тёмная темы, адаптация для мобильных устройств.
  prefers-reduced-motion отключает декоративное движение.
  Схема автоматизации статичная. Связанные объекты на иллюстрациях
  сохранены целиком. Отделена только группа сетевых узлов, окружённая
  полностью прозрачным зазором.

Иллюстрации
  Созданы встроенным image_gen, сохранены с прозрачным фоном.
  Полные промпты: ARTWORK.txt.
